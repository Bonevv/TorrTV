# Услуга за настройки на TorrTV

[worker.mjs](worker.mjs) е предоставеният от собственика Cloudflare Worker с добавени настройки за БГ уеб каталозите. Той управлява профили, вход с номер/ПИН и конфигурация; филмовите каталози се проверяват от приложението.

## Обновяване на съществуващата услуга

1. В Cloudflare → Workers & Pages отвори **съществуващия Worker**, чийто адрес е в `Remote.URL` на приложението.
2. Запази резервно копие на сегашния код. Отвори **Edit code** и замени основния модул със съдържанието на `worker.mjs`.
3. В **Bindings** запази **същото KV пространство** и името на променливата **`DB`**. Там са сегашните профили, ПИН-ове, сесии и общи настройки. Не създавай празно KV и не изтривай записи.
4. Публикувай с **Deploy**. Отвори `/admin` на същия адрес и влез със сегашните данни.
5. В „Общи настройки“ или в конкретен профил се появяват седемте БГ каталога. Профилите наследяват общите настройки, освен когато е избрана „своя стойност“.
6. В TorrTV избери **Обнови настройките**. Съществуващите персонални списъци за уеб плеъри остават със своите стойности; новите стандартни плеъри се добавят в тези списъци ръчно или чрез възстановяване на стандартните адреси.

Качването на този файл в GitHub **не обновява Cloudflare**. В хранилището няма автоматично публикуване на Worker-а или Cloudflare идентификационни данни. Подготвеният Worker не е публикуван от тази среда.

## Ново поле

`web_bg_providers` е списък с разрешени каталози:

| ID | Каталог |
| --- | --- |
| `NINE` | Filmi9 |
| `TWO_K` | Filmi2K |
| `ZENO` | ZenoPlay |
| `ALL` | Всички филми |
| `FEN` | FilmiFen |
| `ZT` | FilmiZT |
| `ZIP` | FilmiZip |

`[]` означава стандартните седем, а `["-"]` изключва всички. Липсваща собствена стойност в профил наследява общата. Неизвестните ID се отхвърлят. Старият Worker остава съвместим с новото приложение, а новият Worker запазва старите полета и `/api/sync` протокола.

Стандартните списъци за уеб плеъри включват допълнително PrimeSrc, AutoEmbed, EmbedHeaven и VAPlayer. Последният е JSON източник, който приложението обработва отделно. Те не доказват наличие на БГ аудио и не се маркират автоматично като български.

## Локална проверка

Изисква се Node.js 18 или по-нов:

```sh
node --test cloudflare/tests/worker.test.mjs scripts/tests/web-subtitle-probe.test.mjs
```

Тестовете използват фиктивно KV и фиктивни данни за вход. Не четат и не променят работещата услуга.
