# TorrTV

Android TV приложение: TMDB каталог → търсене в 6 торент сайта (със сийдъри) → стрийминг директно от торент
→ избираем плеър (вграден / VLC / MX / Just Player) → субтитри от OpenSubtitles, Subdl, SubSource, Subs.sab.bz.
Включва "Зарче" 🎲 - 5 предложения по жанр.

## Първо пускане
1. Добави 4-те secrets (виж `GITHUB_SECRETS.txt`) в Settings → Secrets and variables → Actions.
2. Създай издание: `git tag v1.0.0 && git push origin v1.0.0` (или Actions → Build APK → Run workflow).
3. Свали `TorrTV.apk` от Releases и го инсталирай на телевизора.
4. В приложението: ⚙ Настройки → отвори показания адрес на телефона, въведи ПИН и постави съдържанието на `keys.txt`.

## Обновяване
Нов таг `v1.0.1` → Actions го компилира → в приложението: Настройки → "Провери за обновление" → "Свали и инсталирай".

Ключовете НЕ са в кода - пазят се само на телевизора.
